# Security Policy

## Supported versions

DevOps Sentinel has no release yet. No version is supported.

| Version | Supported |
| --- | --- |
| none | Planning / initial development |

## Reporting a vulnerability

Report security issues privately:

[Open a GitHub security advisory](https://github.com/qiuzhonggu/devops-sentinel/security/advisories/new)

Do not file a public issue, and do not attach exploit details to a pull request.

Include:

- the component you believe is affected
- the impact you expect
- a minimal reproduction, if you have one, with secrets removed
- the commit SHA you tested

We will acknowledge the report, work on a fix, and coordinate what becomes public. Please give us a chance to patch before disclosure.

The design the project intends to implement is in [docs/SECURITY.md](docs/SECURITY.md). That document describes planned controls. It is not a statement that those controls already exist.
